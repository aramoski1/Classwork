## ⚙️ Installation & Usage

**1. Clone the repository**
```bash
git clone https://github.com/aramoski1/Class-Assignments-One.git
cd Class-Assignments-One
```

**2. Create and activate a virtual environment**
```bash
python -m venv .venv

# macOS / Linux
source .venv/bin/activate

# Windows
.venv\Scripts\activate
```

**3. Install dependencies**
```bash
pip install -r requirements.txt
```

**4. Run the code**
```bash
# Run a Python script
python assignments/A01-intro/main.py

# Open the notebooks
jupyter notebook

# Launch a Streamlit app
streamlit run projects/milestone-2/app.py
```
